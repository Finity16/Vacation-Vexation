# Vacation Vexation

Vacation Vexation is a short WarioWare style game, my first project in Godot, made for HackClub Stardance!

Minigames 
- a platformer minigame where you have to collect 3 items
- a clicker minigame where you have to tap 4 items

Every minigame must be completed in 10 seconds, or you will lose a life! Lose all 5 and you'll be gone for good!

All sprites made by me.
Hope you enjoy!
